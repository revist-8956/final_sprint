# 익명 미니 게시판 구현 계획

## 목표

SayScene과 같은 FE·BE 기술 스택으로 아주 작은 게시판을 만든다. 코드를 읽으며 React·TypeScript와 Java·Spring Boot의 표현을 공부할 수 있도록 파일 수와 기능을 줄인다.

## 범위

- 글 목록, 글 작성, 글 상세
- 한 페이지에 글 5개 표시, 연필 버튼으로 글쓰기 전용 화면 열기, 오른쪽 위 버튼으로 취소
- 익명 댓글 작성
- 누를 때마다 증가하는 좋아요
- 로그인, 수정, 삭제, 검색, 실제 클러스터 배포는 포함하지 않는다.

## 구조

- `fe/`: React 19, TypeScript, Vite. 한 화면에서 목록과 상세를 전환한다.
- `be/`: Java 21, Spring Boot 3.5.7, Maven, Spring Data Redis.
- Redis에 글·댓글·좋아요를 저장한다. 좋아요는 원자적 증가 명령을 사용한다.
- API는 `/api/posts` 아래에 둔다. Vite 개발 서버가 `/api`를 BE로 전달한다.
- EKS용 Dockerfile·Kubernetes 설정·ALB Ingress 파일을 준비한다. 실제 적용은 별도 작업이다.

## 순서와 확인 기준

1. 글 작성·목록: 제목과 내용을 쓰면 저장되고 최신 글 목록에 나타난다.
2. 글 상세·댓글: 글을 선택하면 본문과 댓글이 보이고, 새 댓글이 나타난다.
3. 좋아요: 클릭할 때마다 숫자가 정확히 1 증가한다.
4. 마무리: FE 빌드와 BE 테스트를 통과하고 실행·학습 안내를 작성한다.
5. EKS 파일: 이미지 빌드 파일과 `kubectl kustomize` 결과를 확인한다.

## 제한과 위험

- 인증이 없으므로 작성자를 구분하거나 좋아요 중복을 막지 않는다.
- 공개 배포는 이번 작업 범위가 아니다.
- Redis가 실행 중이지 않으면 데이터 API가 작동하지 않는다.
