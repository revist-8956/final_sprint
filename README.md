# final_sprint

## 작은 게시판

React·TypeScript FE, Spring Boot BE, Redis, EKS 실습 설정을 담은 익명 게시판입니다.

| 폴더 | 내용 |
|---|---|
| `fe/` | 화면 코드와 FE Dockerfile |
| `be/` | API 코드와 BE Dockerfile |
| `k8s/` | EKS용 Kubernetes·Ingress 설정 |
| `docs/` | 실행 방법, 학습 안내, 작업 계획 |

로컬 실행과 EKS 준비 방법은 [docs/README.md](docs/README.md)에 있습니다.
